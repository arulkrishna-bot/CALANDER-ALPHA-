# 3D Flip Glassmorphism Dual Calendar (தமிழ் & English) 📅✨

- **உருவாக்கியவர் (Creator)**: MR BOT
- **பதிப்பு (Version)**: v2.5 Pro 3D Edition
- **தொழில்நுட்பம்**: HTML5, CSS3 3D Perspective, Web Audio API, Gemini AI

## முக்கிய அம்சங்கள் (Features):
1. **உருவாக்கியவர் அடையாளம்**: MR BOT அவர்களால் வடிவமைக்கப்பட்ட பிரத்யேக காலண்டர்.
2. **3D Amber Neon Theme**: நீங்கள் விரும்பிய நவீன ஆம்பர் நியான் 3D மேசை காலண்டர் தோற்றம்.
3. **நேரடி கடிகாரம் & கேலெண்டர் ஐகான்கள்**: நேர்த்தியான SVG Calendar & Clock Icons.
4. **3D Flip Interaction**: ஒரே கிளிக்கில் தமிழ் மற்றும் ஆங்கில காலண்டர்களுக்கு இடையே சுழலும் 3D விளைவு.
5. **AI பஞ்சாங்கம், கோலம் & ராசி பலன்**: Gemini AI மூலம் இயக்கப்படும் நிகழ்நேர வானியல் மற்றும் கலை அம்சங்கள்.

## எவ்வாறு இயக்குவது (How to Run):
1. இந்த ZIP கோப்பை அன்சிப் (Extract) செய்யவும்.
2. அதில் உள்ள `index.html` கோப்பை எந்த ஒரு இணைய உலாவியிலும் (Chrome, Firefox, Edge, Safari) திறந்து பயன்படுத்தலாம்!
